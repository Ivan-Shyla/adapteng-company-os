| `GITHUB_CLIENT_SECRET` | Saved GitHub OAuth App secret; locked runtime secret |
| `JWT_SIGNING_KEY` | New random string, at least 48 characters; locked runtime secret |
| `STORAGE_ENCRYPTION_KEY` | New Fernet key, generated by `Fernet.generate_key()`; locked runtime secret |
| `OAUTH_DATA_DIR` | `/data/oauth` |

Generate keys **on your own trusted computer** (do not paste the output into chat):
```powershell
py -c "import secrets; print(secrets.token_urlsafe(48))"
py -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```
The second command requires `cryptography` installed locally; if missing, use `py -m pip install cryptography` and retry. Retain both in a password manager; a changed storage key makes the saved encrypted OAuth registrations unreadable.

In Coolify use locked runtime secret values, not build arguments, and keep output/log redaction enabled.
