# AdaptEng Company OS

Единая точка входа в операционную архитектуру AdaptEng.

- [`ARCHITECTURE.md`](ARCHITECTURE.md) — действующая архитектура, фактический
  статус систем, границы репозиториев, этапы внедрения и AI-план.
- [`FOUNDER_QUESTIONNAIRE.md`](FOUNDER_QUESTIONNAIRE.md) — вопросы владельцу,
  ответы на которые уточнят приоритеты и выпустят версию 1.1.

В этом репозитории нет клиентских документов, персональных данных, паролей,
runtime-дампов и копий реализации из других репозиториев. Изменения архитектуры
делаются через PR и обновляют существующий master-файл, а не создают новый
параллельный план.
