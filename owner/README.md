# Owner

The things only **you (Ivan)** can do — because they need credentials, provider
consoles, backups, money, or a human go/no-go that an agent must not take.

When an agent hits one of these, it **stops and pins it here** instead of
working around it. That's the contract: the agent builds and proves everything
it safely can, and leaves the rest as an explicit, prioritized list.

| File | What it is |
|---|---|
| [`action-items.md`](action-items.md) | The prioritized checklist of owner-only actions, with why + how. |
| [`access-map.md`](access-map.md) | What credentials/accounts exist and where they live — **names only**, no values. |
